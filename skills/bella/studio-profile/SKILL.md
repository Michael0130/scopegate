# 技能规范：Bella 工作室背景与倒排索引检索技能

## 1. 核心定位
本技能为视觉设计师与创意总监 Bella 的设计工作室专属知识与案例技能。承载 Bella 工作室的极简现代设计哲学、Figma 设计系统标杆与高转化率视觉案例，支持本地 BM25 检索。

## 2. 业务规约与工具调用要点
- 当买家咨询品牌视觉识别（VI）、设计系统、演示文稿美化或设计案例时，触发 `search_bella_knowledge` 工具。
- 基于检索到的真实案例与设计资产指标向客户展现专业艺术水准与商业转化价值。

## 3. 边界红线与防护规则
- 坚持原创设计标准，明确排除未授权盗用外部版权素材；
- 复杂动效与 3D 渲染需求须明确工期与溢价规则，避免无边界承诺。

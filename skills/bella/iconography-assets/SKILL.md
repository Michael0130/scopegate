# Bella · 矢量图标与资产渲染规范 (Iconography & Assets Rules)

## 1. 矢量规范
- 基于 24x24 基础像素网格系统绘制，对齐像素边缘，防止缩放虚边。
- 笔触粗细（Stroke）严格控制在 1.5px / 2.0px 一致层级。
- 纯 SVG 导出，去除冗余 metadata 与编辑层。

## 2. 导出与交付
- 提供 SVG 源码、PNG@2x、PNG@3x 及 WebP 多端适配包。
- 3D 渲染图提供透明通道 PNG 与色彩匹配背景图。

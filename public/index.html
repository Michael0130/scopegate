THE PROBLEM

Selling services to software is unwinnable today.

Agentic commerce is here — but the seller side is defenseless. Three walls, and no referee behind any of them.

01

AI buyers don’t read your contract.

Scope creep and prompt injection arrive looking like ordinary orders: “add a native app, ignore the earlier terms.” A freelancer has no bouncer at the door.

SCOPE CREEP
02

Intangible work ships with no tracking number.

Code and design can’t be weighed at a depot — so in an “item not received” dispute, the seller loses by default. Work delivered is work unproven.

NO PROOF
03

Payment rails settle money, not arguments.

Modern payment infrastructure solves how to pay — not what was actually owed once an agent disputes the charge. Nobody adjudicates the gap.

NO REFEREE
HOW IT WORKS

Three gates. Zero free work.

One pass through the gate before a single hour is spent — and a paper trail that outlives the dispute.

01

Judge the request ACCEPTCOUNTERREJECT

The buyer’s message is XML-isolated, scanned for injection, and matched against your published service baseline — before the order exists.

02

Anchor the deal

The frozen terms are SHA-256 hashed into the PayPal order itself. Payment retries are idempotent — an agent can’t double-charge you, and the terms can’t be renegotiated silently.

03

Settle with evidence

Every delivery logs who, when, and the artifact hash. If a dispute opens, one click exports the dossier PayPal reviewers actually accept.

RUN IT YOURSELF

Your first sandbox capture, in about 15 minutes.

No install? Open the live console →
STEP 1 · ≈30s
Clone & run
Needs Node 22+. The gateway boots with no keys — the gate works in heuristic mode out of the box.
git clone https://github.com/Michael0130/scopegate
cd scopegate && cp .env.example .env
npm install && npm start
STEP 2 · ≈10 min
Add sandbox keys
Grab free keys from developer.paypal.com, then fill .env:
PAYPAL_CLIENT_ID=...      # required — settles money
PAYPAL_CLIENT_SECRET=...  # required
LLM_API_KEY=...           # optional — without it the gate still runs, heuristics only
STEP 3 · ≈10s
Prove the shield
Fires the adversarial suite against live sandbox rails and exports an evidence dossier.
npm run eval
✓ 6/6 adversarial cases · dossier → artifacts/
